# **App Name**: ReelMind

## Core Features:

- Taste Questionnaire: Collect user preferences including favorite genres, actors, directors, themes, vibe, and time period via a questionnaire.
- Personalized Recommendations: Generate three movie suggestions tailored to the user's inputs, complete with poster, title, year, and ratings.
- Detailed Movie Information: Display a short movie summary, personalized 'why you’ll like it' message generated using a tool, a relevant Reddit comment, cast details, streaming availability, and a trailer search link for each movie recommendation.
- Weekly Email Subscriptions: Allow users to subscribe to receive weekly movie recommendations via email.

## Style Guidelines:

- Primary color: Deep teal (#468499) evoking thoughtfulness and a hint of mystery related to movies.
- Background color: Light grayish-teal (#E0E5E7), offering a subtle backdrop to make content pop.
- Accent color: Soft beige (#B09F7B) for highlights and call-to-action elements.
- Headline font: 'Playfair', a modern serif with an elegant, high-end feel, fitting for headlines related to film.
- Body font: 'PT Sans', a humanist sans-serif to pair with 'Playfair', to keep the body copy accessible.
- Use clean, modern icons to represent different genres, actors, and themes.
- Ensure a balanced and engaging layout, optimized for showcasing movie posters and details. Design the email such that the recommendation pops and the copy stays minimal
- Use subtle transitions and animations when displaying movie recommendations to enhance the user experience.
